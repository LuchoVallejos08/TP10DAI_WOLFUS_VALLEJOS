# Trabajo Practico de Repaso

# Operacion Rescate II: El Backend Perdido

## Contexto

Durante las vacaciones, otro desarrollador decidio mejorar el backend del sistema del supermercado.
Antes de irse hizo cambios sin documentar y ahora el proyecto tiene multiples fallas.

Tu equipo debe rescatar el proyecto investigando, detectando, corrigiendo y documentando errores.

No deben crear una API nueva. Deben reparar la existente.

## Objetivos

Aplicar conocimientos de:

- Node.js
- Express
- Rutas
- Middleware
- JWT
- Autenticacion
- Autorizacion
- Manejo de errores
- Organizacion del proyecto

## Tareas

Cada grupo debe:

- Ejecutar el proyecto.
- Detectar errores.
- Corregirlos.
- Verificar que funciona.
- Documentar cada problema encontrado.

## Requisitos funcionales

El proyecto final debe permitir:

- Registrar usuarios.
- Iniciar sesion.
- Obtener un JWT valido.
- Acceder solo a rutas protegidas con token valido.
- Rechazar solicitudes sin token.
- Rechazar tokens invalidos.
- Responder con codigos HTTP correctos.

## Entrega

- Proyecto corregido.
- Informe de errores.
- Breve explicacion tecnica de las soluciones.
